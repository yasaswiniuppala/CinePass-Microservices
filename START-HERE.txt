CINEPASS — QUICK START
=====================
Recommended: Docker Compose
1) Install Docker Desktop.
2) Copy .env.example to .env and set a unique JWT_SECRET (32+ bytes).
3) Run: docker compose up --build
4) Open http://localhost:8761 (Eureka) and http://localhost:8080 (Gateway).
5) Run review1-tests.http in VS Code with the REST Client extension.

Local alternative: Java 17+, Maven 3.9+, MySQL 8+. Run database/setup.sql, then `mvn clean package`, start Eureka, User, Movie, Show, Booking and Gateway in that order.

See README.md for complete API examples, design notes, testing and troubleshooting.
